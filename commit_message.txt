Implemented the core peak detection algorithm using a watershed-style approach. Added cells to detect local maxima in gene expression time series based on gradient analysis. The algorithm identifies peaks (expression maxima) corresponding to specific cell cycle phases where genes are most active.

The watershed approach works by:
- Computing expression gradients to find local maxima
- Identifying peaks above a threshold
- Annotating peak positions on visualizations

Applied the algorithm to a single test gene (gene 766) first to validate correctness before applying to multiple genes. The detected peaks align with biological expectations for cell cycle gene expression.

Verified: Algorithm detects peaks correctly on test gene, peak positions match visual inspection of expression profile.
